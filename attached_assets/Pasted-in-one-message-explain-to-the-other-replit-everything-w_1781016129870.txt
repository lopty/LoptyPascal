PROBLEM WE SOLVED
React SPAs serve an empty <div id="root"></div> to bots. Googlebot renders JS eventually, but AI crawlers and social previewers see nothing. The fix is static prerendering: at build time, every URL renders to a complete HTML file using React's renderToString. Bots get full HTML. Users get the React SPA.

THE 4-FILE PRERENDER SYSTEM

1. src/entry-server.jsx

import { renderToString } from 'react-dom/server'
import { StaticRouter } from 'react-router-dom'
import App from './App.jsx'
import { getSeoRoute, seoRoutes } from './seo/routes'
import { getStructuredData } from './seo/schema'
export { getSeoRoute, getStructuredData, seoRoutes }
export function render(url) {
  return renderToString(<StaticRouter location={url}><App /></StaticRouter>)
}

2. vite.ssr.config.ts — builds the SSR bundle, no PORT needed, outputs to dist/server/, ssr: 'src/entry-server.jsx'

3. src/seo/routes.js — single source of truth for every public URL. Each route object: { path, title, description, canonical, image, schemaType, breadcrumb, faq, lastModified }. All routes merged into exported seoRoutes[].

4. prerender.js — iterates seoRoutes, calls render(url), builds full <head> block (title, description, canonical, OG, Twitter, JSON-LD), injects both into index.html template, writes dist/public/{slug}/index.html for every route.

Build script in package.json:

"build": "vite build --config vite.config.ts && vite build --config vite.ssr.config.ts && node prerender.js"

Run locally as: PORT=3000 BASE_PATH=/ pnpm run build

index.html needs these markers so prerender can inject per-page tags:

<!-- SEO_START -->
<title>...</title>
... default meta ...
<!-- SEO_END -->

STRUCTURED DATA (JSON-LD via src/seo/schema.js)

Function getStructuredData(route) returns a @graph array injected into every page's <head>. Schema types by page:

Homepage: Organization + WebSite + Person + WebPage + BreadcrumbList + FAQPage
Service/topic pages: Organization + Person + WebPage + BreadcrumbList + FAQPage
Geo pages: Organization + Person + WebPage + BreadcrumbList (geo-targeted)
Blog/articles: Organization + Person + Article + WebPage + BreadcrumbList
Comparison pages: Organization + Person + WebPage + BreadcrumbList
For a personal brand, Person schema is the anchor (replaces SoftwareApplication). It should include: name, jobTitle, url, sameAs (LinkedIn, Twitter/X, YouTube), knowsAbout, address (for geo signals), image.

KEY GOTCHAS FROM OUR BUILD

vite.config.ts throws if PORT env var is missing — pass PORT=3000 for builds
Any component that uses SeoJsonLd must import it — missing import causes prerender failure for that page
Every route in App.jsx must also be in seoRoutes in routes.js or it won't be prerendered
Check actual export names in content files before importing (e.g. extComparisons not comparisonsExt)
SeoMeta component handles client-side navigation meta updates via useEffect + document.head — keep this for single-page transitions
